# Junji Ito Manga Indonesia — Mihon source module

A source module for the Keiyoushi `extensions-source` build system. This repository is source code; it is **not** a standalone installable APK or Mihon extension repository.

## Source
- Website: https://junjiitomangaindonesia.blogspot.com/
- Catalog: https://junjiitomangaindonesia.blogspot.com/p/kumpulan-manga-junji-ito-bahasa.html
- Language: Indonesian (`id`)
- Source package: generated by Keiyoushi build tooling

## Current behavior
- Reads linked Blogger posts from the catalog page.
- Uses each linked post as a manga/gallery entry.
- Exposes one `Full story` chapter per post.
- Extracts images from the post body.
- Follows links labelled `HALAMAN SELANJUTNYA` to gather same-story pages, with a 40-page cap and cycle detection.
- Does not follow `BERSAMBUNG KE BAB SELANJUTNYA` links, which point to another story/chapter.

## Build and validation

This module must be built inside a compatible checkout of the current Keiyoushi `extensions-source` repository. Read its contribution guide first:
https://github.com/keiyoushi/extensions-source/blob/main/CONTRIBUTING.md

1. Fork and clone https://github.com/keiyoushi/extensions-source
2. Copy `src/id/junjito` into the checkout's `src/id/junjito`.
3. Build using the upstream Gradle wrapper and the currently supported JDK:
   ```bash
   ./gradlew :src:id:junjito:lintRelease
   ./gradlew :src:id:junjito:assembleDebug
   ```
   If Gradle reports a different project path, inspect `./gradlew projects` and use the path it lists.
4. Install the debug build in a test Mihon profile and verify catalog, search, manga details, and image order.

**Validation status:** this repository upload has not yet been compiled against a complete upstream checkout or tested on an Android device. Treat a successful upstream lint/build and an on-device smoke test as required before release.

## Limitations
- Catalog entries without actual Blogger post links cannot be opened.
- The catalog uses a favicon fallback thumbnail until details are fetched.
- Blogger markup and image hosting can change; selectors may need updates.
- Use only to access content you are authorized to read. Respect the site owner's terms and support official releases.
